# Hydra

Hydra is a  small 2D Rust game framework powered by SDL3.

## Features

- SDL3 window and renderer setup
- Simple entity/component-style game loop
- Shape and sprite rendering
- Keyboard and mouse event handling



## Project structure

- `src/` contains the engine, game loop, rendering code, and example gameplay logic.
- `libs/` includes the SDL3 runtime libraries used by the project.
